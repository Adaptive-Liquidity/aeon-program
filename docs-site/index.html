AEON

The economic control plane for autonomous AI agents · v0.2.0
Anchor 0.30.1 · 20 instructions · TypeScript Agent SDK · fail-closed spend · live on devnet
Not a yield / APY / emissions product.
Autonomous agents are starting to move real money — and today their spending power is a hot private key. One prompt injection or buggy planner loop drains the wallet. Off-chain guardrails are suggestions; nothing enforces them.

AEON moves enforcement on-chain. An agent never holds open-ended spend power — it holds a scoped authority: budgeted, category-limited, depth-capped, expirable. Every debit is accounted for by the program itself: if the token transfer fails, the ledger does not move. Misbehaving branches are revoked in a cascade and their bonds slashed. Every action leaves a tamper-evident, hash-chained receipt bound to the agent's identity.

The six primitives

PrimitiveWhat it gives agents
IdentityAgent registration + non-transferable CRI (Cryptographic Reputation Index) accumulating volume and commitments
Scoped authorityHierarchical grants: budget · max-per-tx · max-total · category whitelist · expiry · depth ≤ 3. Children never exceed the parent's remainder
Fail-closed spendpay / atomic_split / escrow: policy → token CPI → commit. Hostile mints can stop money; they cannot falsify the ledger
EscrowConditional locks (immediate / oracle / timeout) with release and cancel paths
OrganizationsMulti-agent swarms with share-based treasury claims; dissolution requires the complete share set — no silent siphons
Provenance & teeth v0.2Hash-chained CRI-bound receipts · admin pause kill switch · scheduled authority expiry · slashable bonds
